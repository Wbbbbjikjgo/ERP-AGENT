# 报告生成技能

## 概述
将采购数据和分析结果自动生成结构化报告，支持 Markdown/HTML/CSV 格式。

## 使用流程
1. 收集数据（供应商/零件/订单/库存）
2. 分析处理（计算 KPI 指标）
3. 生成图表（关键指标可视化）
4. 输出报告（generate_document）

## 报告模板
- 供应商季度评估报告
- 库存周转分析报告
- 采购成本分析报告
- 订单执行情况报告
